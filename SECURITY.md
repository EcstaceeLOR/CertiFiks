# Security policy

**CertiFiks is pre-release engineering work and has not undergone an independent smart-contract or sandbox security audit. Do not deposit real value or treat any address as a supported deployment.**

Report suspected vulnerabilities privately to the repository maintainer through a GitHub private vulnerability report (if enabled), or via a private channel agreed with the maintainer. Do not expose exploit details or private credentials in public GitHub issues. Reproduction reports should omit real API tokens, secret keys and user content.

Security threat model: [docs/security/THREAT_MODEL.md](docs/security/THREAT_MODEL.md). Mainnet launch is blocked pending actual security reviews, lifecycle tests and an enforceable dispute fallback. No public bug bounty payout is currently offered.
